# Agent Authoring Rules

## Naming

- Requirements: `FR-*`, `NFR-*`
- Test cases: `TC-*`
- Acceptance criteria: `AC-*`
- Architecture decisions: `ADR-*`

## Writing Standards

- Use measurable language.
- Avoid ambiguous terms (`maybe`, `probably`, `etc.`) in requirements.
- Every behavior statement must be testable.

## Traceability

- No new behavior without requirement IDs.
- No test case without linked requirement IDs.
- Update traceability matrix whenever requirements, contracts, or tests change.
